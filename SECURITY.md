# Security

TC-0 is experimental local research software. It parses local scenario files and writes reports/trace files to explicitly selected paths. It has no network listener, credentials or service boundary.

Report ordinary simulator, scenario, metric, CLI or replay discrepancies in [public issues](https://github.com/Kesh3805/temporal-compute/issues/new/choose) with a minimal scenario and commit. A policy losing utility or an unsupported research interpretation is not automatically a security vulnerability.

For a suspected vulnerability, use [GitHub private vulnerability reporting](https://github.com/Kesh3805/temporal-compute/security/advisories/new). Include the affected commit, minimal reproduction, impact and relevant platform details. Keep confidential workloads, credentials and sensitive exploit details out of public issues, Discussions and traces. If private reporting is unavailable, use the repository owner's [GitHub profile](https://github.com/Kesh3805) to identify an available contact route before disclosing details; no email address or response deadline is promised here.

Only the current main branch is maintained. No flight qualification or operational safety assurance is provided.
