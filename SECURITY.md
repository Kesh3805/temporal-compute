# Security

TC-0 is experimental local research software. It parses local scenario files and writes reports/trace files to explicitly selected paths. It has no network listener, credentials or service boundary.

Report correctness issues publicly with a minimal scenario and commit. For a vulnerability involving confidential material, use GitHub's private vulnerability reporting when available; otherwise contact the maintainer through the repository profile before sharing sensitive details. Only the current main branch is maintained. No flight qualification or operational safety assurance is provided.
