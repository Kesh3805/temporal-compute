# Bounded native integration validation

This is host-independent implementation correctness evidence authorized after
PR #21, not renderer selection, amendment adoption or a scientific comparison.
The actual execution host remains pending. GitHub Actions may build the selected
CPU kernel and execute this finite non-primary matrix as validation only.

The contract and original synthetic fixtures are committed before implementation
or results. Freeze the existing absolute-plus-relative tolerance:
`abs(a-b) <= 1e-6 + 1e-5 * max(abs(a),abs(b))`, applied to every RGB value.
Require exact pixel/index ownership, exact class counts and complete Film domains
separately from numerical estimator comparisons. EXR bytes are diagnostic only;
nonzero-begin EXR normalization is not the progressive estimator.

For each of three 16x16 fixtures (environment, diffuse, mixed surface paths):
one-shot [0,16), four ordered four-spp batches, reversed batch invocation,
one versus two threads, and reversed quadrant traversal. Independently compare
every intermediate Film pixel to its cumulative native sample mean. Compare
sample identities, classes and RGB values across partitions and aggregate the
complete Film estimators with sample-count weights. Compare the production kernel
image against the native one-shot Film. No reference or image-quality metric.

On the diffuse fixture, exercise all three conventional policies, TC and both
ablations through the existing paired runner for ten decisions on two 128-pixel
regions. Independently reconcile exact per-pixel prefixes, projected independent
seeds, both charged ledgers, mandatory 16-spp initialization and complete four-spp
requests. Verify observed conventional candidate equations independently; this
does not establish that the strong baseline is competent at primary scale.

On the separate 8x8 environment fixture, exercise actual threshold crossings at
`2*8*8*16*17 + [4096,16384] = [38912,51200]`. These are **synthetic test thresholds**,
not the proposed or registered scientific budgets. The pair bound is 8704 rays;
retain actual initialization charge, nominal threshold, actual charge and overshoot.
Require complete initialization before scoring and actual class sums only.
No fabricated reserve charge, truncated request or second-stream omission.

Fault tests dispatch the real binary, then deliberately retain and truncate a
sample log, and separately terminate a freshly launched process. Require retained
unknown-work failure, rollback, denied image/scoring and no silent retry. Also
interrupt the second stream of a real paired request; no paired result may escape.
Preserve original logs beside intentional corruptions. Caught interruptions are
test faults, never permission to replay an uncertain request.

Parse all 30 exact-hashed primary assets only through pinned PBRT `--format`.
It invokes the formatting parser without rendering; it is syntax evidence, not
runtime material construction. Retain every command, exit status, stdout/stderr
and failure; reverify the corpus before and after. Render admission is restricted
to these four separately hashed synthetic fixtures.

Bound effort to 800 native commands, 600 seconds per dispatch and one 45-minute
validation workflow attempt. The execute marker permits only first introduction
in prior reachable history and attempt 1. Review/doc pushes do not retrigger it.
Do not invoke the E3 workflow. Any identity/estimator/accounting/class-bound or
checkpoint invariant failure stops the gate and retains a blocker; do not patch
the scientific assumptions, assets, instrumentation or thresholds in response.

Retain source/configuration hashes, actual binary/toolchain/submodule provenance,
native samples/events/Film, intentional-fault evidence, all parser diagnostics,
report and complete artifact hashes. A PASS applies only to the tested matrix.
Selected-host threading, isolation, timing/filesystem checks, baseline competence,
stopping/censoring and reference authorization remain separate open decisions.
Amendment 0002 stays inactive; no primary outcomes, references or execution tag.
